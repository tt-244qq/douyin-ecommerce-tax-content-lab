# 找电商代账先问三句话

**账号**: 西安注册公司找峪诚
**内容形态**: 25-30 秒真人电商财税短视频
**目标人群**: 准备更换代账或感觉现有账务跟不上平台业务的电商老板
**视频目标**: 用三个问题筛选高意向客户，并私信“代账”

## 口播稿

电商老板找代账，别先问一个月多少钱，先问三句话。第一，平台成交、退款、补贴能不能按店铺拆？第二，无票支出和私户流水，会不会提醒你补材料？第三，每个月能不能给一张收入费用对账表？三句都答不清，再便宜也只是记账，不是在管风险。要完整问题清单，私信我“代账”。

## 视频设计

**风格矩阵**: 真人面试官 + 三问翻牌板。
**拍摄方式**: 用户真人原声拍摄，人物贯穿主画面；每说一个问题，用手势数一、二、三，后期在左右两侧加问题卡。
**首屏**: 真人直视镜头，大字“找代账，先别问价格”。
**分镜**:

1. 0-4 秒：真人否定“先问价格”，价格标签缩小退出。
2. 4-19 秒：三张问题卡依次翻开，每张只保留一个关键词：按店拆、补材料、月度对账。
3. 19-24 秒：三张卡全部打勾，红字“答不清 = 只记账”。
4. 最后 3 秒：真人主画面，CTA“私信：代账”。

**字幕策略**: 真人口播为主；三张问题卡承载可截图信息。
**封面大字**: 找代账，先问这 3 句
**私信关键词**: 代账

## 发布承接

置顶评论：电商代账先问能不能按店拆、会不会提醒补材料、每月有没有对账表。
