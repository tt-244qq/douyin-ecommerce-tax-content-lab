# 作品生成说明

## 生成模式

本轮采用“电商财税口播 + 大字字幕 + 快切 B-roll 素材”的短视频模式。

选择原因：

- 抖音企业号获客更需要信任感和专业确定性，不适合纯混剪爽感。
- 财税内容的核心是把风险说清楚，大字字幕能提高静音观看理解率。
- 现阶段没有王禹喆真人拍摄素材，先用电商后台、账面利润、证据链、主体选择等视觉符号做样片。

## 工具链

- MoneyPrinterTurbo 安装位置：`/mnt/d/wtf1124/project/MoneyPrinterTurbo`
- Python 环境：MoneyPrinterTurbo 项目内 `.venv`
- TTS：MoneyPrinterTurbo 默认 Edge TTS，男声 `zh-CN-YunyangNeural`
- 视频比例：竖屏 `9:16`
- 输出规格：`1080x1920`、`30fps`
- 字幕：MoneyPrinterTurbo 生成 SRT，使用自带 ffmpeg 烧录到视频

说明：MoneyPrinterTurbo 的最终封装函数在当前环境会卡住收尾，所以本轮采用稳定链路：

1. MoneyPrinterTurbo 生成音频、字幕、素材拼接视频。
2. 使用 MoneyPrinterTurbo 环境内的 ffmpeg 完成字幕烧录、音频合成和 mp4 封装。
