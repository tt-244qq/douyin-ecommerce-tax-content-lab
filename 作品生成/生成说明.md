# 作品生成说明

## 本轮目标

重做三条抖音短视频样片，解决上一版排版结构过于一致的问题。

本轮采用“同一账号体系，不同内容容器”的方式：

- 统一品牌露出：`西安注册公司找峪诚`
- 统一底部转化：私信关键词
- 每条视频使用不同视觉结构，避免连续发布时像模板套壳

参考账号详见本地隐私文件。本项目只参考“同一账号下用不同场景容器承载观点”的内容方法，不复制画面和人设。

## 三条视频结构

### 01 无票成本

- 内容容器：冲突剧场
- 视觉主题：老板感觉利润不高 vs 账面利润被放大
- 核心元素：左右对抗、红色风险、飞入票据、利润数字放大
- 系列编号：`01/03`
- 私信关键词：`成本`

### 02 平台流水自查

- 内容容器：风险侦查
- 视觉主题：平台流水、收款账户、已开票金额三数对齐
- 核心元素：雷达扫描、数据卡片、红色预警、风险锁定
- 系列编号：`02/03`
- 私信关键词：`电商自查`

### 03 主体选择

- 内容容器：决策选择器
- 视觉主题：个体户和公司不是只看税低不低
- 核心元素：决策树、选项卡、勾叉判断、主体路径
- 系列编号：`03/03`
- 私信关键词：`主体`

## 生成链路

1. 将三条原始内容重写为差异化风格口播。
2. 使用 MoneyPrinterTurbo 生成口播音频和字幕时间轴。
3. 使用本地程序生成三条不同视觉结构的 60fps 动画底片。
4. 使用 MoneyPrinterTurbo 环境内的 ffmpeg 烧录字幕、合成音频、封装成 mp4。
5. 使用 ffmpeg 校验分辨率、帧率和时长。
6. 抽帧检查品牌、编号、关键词和画面结构。
