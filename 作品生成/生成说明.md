# 作品生成说明

## 本轮目标

重做三条抖音短视频样片，解决上一版排版结构过于一致的问题。

本轮采用“同一账号体系，不同内容容器”的方式：

- 统一品牌露出：`西安注册公司找峪诚`
- 统一底部转化：私信关键词
- 每条视频使用不同视觉结构，避免连续发布时像模板套壳

参考账号详见本地隐私文件。本项目只参考“同一账号下用不同场景容器承载观点”的内容方法，不复制画面和人设。

## 生成链路

1. 默认读取当天 `scripts/` 下的目标脚本。
2. 使用 MoneyPrinterTurbo 生成口播音频和字幕时间轴。
3. 按 `作品生成/视频风格与元素库.md` 的公共模板生成视频。
4. 使用 MoneyPrinterTurbo 环境内的 ffmpeg 烧录字幕、合成音频、封装成 mp4。
5. 使用 ffmpeg 校验分辨率、帧率和时长。
6. 抽帧检查品牌、关键词、安全区和画面结构。

## 输入来源
